# BRT Dashboard

A real-time transit dashboard for Karachi BRT Green Line with bus tracking, ETA estimates, delay statistics, and station monitoring.

## Screenshot

![BRT Dashboard Screenshot](./screenshot.png)

> Replace `screenshot.png` with your actual image file in the repo.

## Tech

- React
- Vite
- Supabase
- Leaflet
- Vercel

## Features

- Live bus positions on a Leaflet map
- Bus details with ETA to Numaish
- Station list sidebar with search, sorting, and delay status
- Delay graph and fleet statistics
- PDF export for reports
- Responsive layout for desktop and mobile

## Getting Started

```bash
npm install
npm run dev
```

Open the app at `http://localhost:5173`.

## Build

```bash
npm run build
```

## Preview

```bash
npm run preview
```

## Deployment

This project is ready to deploy to Vercel. Create a Vercel project and connect to this repository.

If you use Supabase, set your Supabase environment variables in Vercel for deployment.
